# 🏁 Flagged Maze Game with Reinforcement Learning (Python + Pygame)

An AI-powered maze navigation game where an agent learns to find a flag inside a maze using **Q-learning**, implemented in **Python** with **Pygame** for real-time visualization. The project explores reinforcement learning techniques to solve path-finding problems.

---

## 🧩 Motivation

This project combines classical maze problems with reinforcement learning to develop an agent that optimizes its navigation strategy over time. It showcases how AI techniques like Q-learning can be applied to learn optimal paths in an unknown environment, with visual feedback using Pygame.

---

## 🕹️ Features

- 🧠 **Reinforcement Learning Agent**: Uses Q-learning algorithm to learn the best path to the flag.
- 🏁 **Maze Environment**: Grid-based maze with walls and a flag goal.
- 🎮 **Pygame Visualization**: Real-time rendering of the maze, agent’s position, and learning progress.
- 📈 **Learning Visualization**: Watch the agent improve over episodes with visible updates of its path choices.
- 🔄 **Training & Testing Modes**: Train the agent or watch it use its learned policy to navigate.

---

## 🔧 Technologies Used

- **Python 3**
- **Pygame** – Visualization of maze and agent movements
- **NumPy** – For Q-table and matrix operations
- **Reinforcement Learning (Q-learning)** – Core algorithm for training the agent

---

## 🧪 Learning Outcomes

- Implemented **Q-learning** to solve a maze navigation problem.
- Developed an understanding of **state-action values (Q-values)** and policy improvement.
- Integrated AI with graphical feedback using **Pygame**.
- Gained experience in training agents over multiple episodes and analyzing learning curves.
